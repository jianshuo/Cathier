# 情绪定义草稿 — 全部80+情绪词

请审阅每个定义是否准确、简洁、有区分度。每条定义控制在20-40字。

---

## 激情 (Impassioned)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 热情 | 由内而发的强烈兴趣和投入感，想要全力以赴 | 兴奋 | 热情更持久、有方向感；兴奋更短暂、更生理性 |
| 兴奋 | 面对期待之事时的高度唤醒状态，心跳加速、坐不住 | 激动, 热情 | 兴奋偏向愉快的期待；激动可能不完全是正面的 |
| 激动 | 情绪被强烈触发后的高度亢奋，难以平静 | 兴奋 | 激动的强度更高、更难自控；兴奋更轻快 |
| 狂喜 | 极度的快乐，感觉整个人都在发光，超越日常体验 | 欣喜若狂 | 狂喜更短暂、更像爆发；欣喜若狂更持续 |
| 充满激情 | 对某件事有深层的热爱和驱动力，愿意为之燃烧 | 热情 | 充满激情更深沉、更持久；热情更外露 |
| 欣喜若狂 | 不可遏制的巨大喜悦，感觉世界都在为你庆祝 | 狂喜 | 欣喜若狂持续更久；狂喜更像一瞬间的巅峰 |
| 激动万分 | 被某个消息或事件激起的极度兴奋，全身都在响应 | 兴奋, 激动 | 激动万分有明确的触发事件；兴奋可以没有原因 |
| 坚定 | 内心清晰地知道方向，不会被动摇的确定感 | 自信 | 坚定侧重意志力和决心；自信侧重对能力的信任 |
| 自信 | 对自己的能力和判断有充分的信任感 | 坚定 | 自信来自能力评估；坚定来自价值选择 |
| 乐观 | 相信事情会往好的方向发展的倾向 | 充满希望 | 乐观是一种性格倾向；充满希望更针对具体的事 |
| 期待 | 对即将发生的事情怀有积极的想象和盼望 | 兴奋 | 期待指向未来、还没发生；兴奋是当下的感受 |

## 快乐 (Happy)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 喜悦 | 发自内心的快乐，像有光从心里透出来 | 高兴 | 喜悦更深层、更安静；高兴更外显、更即时 |
| 幸福 | 对当下生活状态的深层满意和感恩 | 满足 | 幸福更全面、更深沉；满足更具体、更当下 |
| 被逗乐 | 被有趣的事情逗笑，轻松愉快的感觉 | 愉悦 | 被逗乐有明确的外部触发（笑点）；愉悦更弥散 |
| 高兴 | 遇到好事时自然产生的愉快反应 | 喜悦 | 高兴更即时、更表层；喜悦更深层 |
| 幸运 | 感觉被好运眷顾，事情出乎意料地顺利 | 感恩 | 幸运侧重"运气好"；感恩侧重"感谢" |
| 感恩 | 对所拥有的或他人的帮助心怀感谢 | 幸福 | 感恩有明确的对象；幸福是一种整体状态 |
| 充满希望 | 相信某件具体的事会有好结果 | 乐观 | 充满希望针对具体的事；乐观是一种整体态度 |
| 充满活力 | 身体和精神都处于饱满状态，想要动起来 | 兴奋 | 充满活力偏身体层面的能量感；兴奋偏情绪层面 |
| 愉悦 | 舒适而温和的快乐，不强烈但很舒服 | 高兴 | 愉悦更轻柔、更持续；高兴更明确 |
| 温暖 | 被善意、关怀包围时内心柔软的感受 | 幸福 | 温暖通常与人际关系有关；幸福范围更广 |

## 平静 (Calm)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 平和 | 内心没有波澜，一切都恰到好处 | 宁静 | 平和侧重心态上的不争；宁静侧重环境的安静 |
| 放松 | 紧绷感消散后身心松弛的状态 | 舒适 | 放松是从紧绷到松弛的变化；舒适是一种稳定状态 |
| 满足 | 当下所拥有的已经足够，不需要更多 | 平和 | 满足有"够了"的判断；平和没有判断 |
| 宁静 | 内外都很安静，像湖面无风 | 平和 | 宁静更有画面感、更寂静；平和更偏心态 |
| 舒适 | 身体和环境都让人觉得恰好、不需调整 | 放松 | 舒适偏物理感受；放松偏从紧绷中释放 |
| 专注 | 全部注意力集中在一件事上，其他杂念消失 | 从容 | 专注是注意力的聚焦；从容是节奏的掌控 |
| 从容 | 不慌不忙，掌握着自己的节奏 | 平和 | 从容有"掌控感"；平和是"无所求" |
| 淡然 | 对外界的变化不太在意，保持距离感 | 从容 | 淡然有情感上的疏离；从容是主动的沉稳 |
| 安然 | 一切都安好，内心没有不安的因素 | 平和 | 安然更强调"安全感"；平和更强调"平衡" |

## 爱与关怀 (Love / Regard)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 充满爱 | 对某人或某事怀有深厚而温柔的感情 | 充满柔情 | 充满爱范围更广（亲情/友情/爱情）；柔情更细腻 |
| 充满柔情 | 心变得很软，想要温柔地对待对方 | 充满爱 | 柔情是爱的一种表现方式，更细腻、更温柔 |
| 钦佩 | 对他人的品质或成就由衷地敬重 | 友好 | 钦佩含有"仰望"的成分；友好是平等的善意 |
| 同情 | 感受到他人的痛苦，想要帮助或安慰 | 充满爱 | 同情由他人的苦难触发；充满爱不需要苦难 |
| 友好 | 对他人怀有善意和亲近感 | 温暖 | 友好更偏社交层面的态度；温暖更偏内心感受 |

## 愤怒 (Anger)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 狂怒 | 愤怒到了极点，理性几乎被淹没 | 愤慨 | 狂怒更失控、更个人化；愤慨有道义上的正当感 |
| 愤慨 | 对不公正之事的强烈愤怒，觉得"这不应该" | 狂怒 | 愤慨含有道德判断；狂怒是纯粹的情绪爆发 |
| 烦躁 | 被反复的小刺激磨得心烦意乱 | 恼火 | 烦躁更弥散、找不到具体原因；恼火有明确的对象 |
| 恼火 | 被某人或某事惹恼，不耐烦 | 烦躁 | 恼火有明确的触发点；烦躁可能原因不明 |
| 怨恨 | 觉得被亏待后长期积累的不满和敌意 | 不满 | 怨恨是长期积累的、带有敌意；不满更轻、更即时 |
| 不满 | 对现状或结果觉得不够好、不符合期望 | 烦躁 | 不满是一种评判；烦躁是一种身体状态 |
| 嫉妒 | 看到他人拥有自己想要的东西时的痛苦感 | 不满 | 嫉妒指向具体的人和他拥有的东西；不满更泛化 |
| 挫败 | 努力了但没有得到想要的结果，感到无力 | 沮丧 | 挫败侧重"努力无效"；沮丧侧重"情绪低落" |

## 恐惧 (Fear)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 紧张 | 面对压力情境时身体绷紧、心跳加速 | 焦虑 | 紧张通常有明确的情境且短暂；焦虑更持久弥散 |
| 担心 | 对某件具体的事情放心不下 | 焦虑 | 担心有明确对象（"担心考试"）；焦虑可能说不清在担心什么 |
| 害怕 | 面对具体的威胁时想要退缩或逃避 | 惶恐 | 害怕有明确的威胁对象；惶恐更弥散、更深层 |
| 焦虑 | 对不确定的未来持续担忧，常伴随身体紧绷 | 担心, 紧张 | 焦虑最弥散、最持久；担心更具体；紧张更短暂 |
| 压力大 | 感觉任务或责任超出了自己的承受能力 | 焦虑 | 压力大有具体的负荷来源；焦虑可能没有 |
| 不安 | 隐约觉得有什么不对，但说不清楚 | 焦虑 | 不安更模糊、更直觉性；焦虑更认知层面 |
| 慌乱 | 突然失去了对局面的掌控，不知道该怎么办 | 害怕 | 慌乱侧重"不知所措"；害怕侧重"想逃避" |
| 惶恐 | 被深层的恐惧笼罩，感到极度不安全 | 害怕 | 惶恐更深层、更持久；害怕更即时 |

## 悲伤 (Disheartened)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 难过 | 遇到不好的事情后心里不舒服 | 沮丧 | 难过更朴素直接；沮丧带有"泄气"的感觉 |
| 孤独 | 缺少陪伴或理解，感到与世界隔绝 | 失落 | 孤独是关系层面的匮乏；失落是期望落空 |
| 受伤 | 被他人的言行刺痛了，内心有创口 | 委屈 | 受伤更强调"痛"；委屈更强调"不公平" |
| 抑郁 | 长时间的情绪低沉，对什么都提不起兴趣 | 沮丧 | 抑郁更深、更持久、更全面；沮丧更短暂 |
| 精疲力尽 | 身体和心理的能量都被耗完了 | 压力大 | 精疲力尽是结果（已经耗完）；压力大是过程（正在承受） |
| 失落 | 期望没有实现，心里空了一块 | 遗憾 | 失落更偏情绪感受；遗憾更偏认知判断（"可惜了"） |
| 委屈 | 受到了不公平的对待，但没有被理解 | 受伤 | 委屈含有"不公平"的判断；受伤是纯粹的痛 |
| 沮丧 | 事情不顺利后泄了气，提不起劲 | 难过, 挫败 | 沮丧是难过+无力的混合；挫败侧重"努力白费" |
| 哀伤 | 深沉的悲痛，通常与重大的失去有关 | 难过 | 哀伤更深沉、更庄重；难过更日常 |
| 遗憾 | 觉得"如果当初那样就好了"的惋惜 | 后悔 | 遗憾接受了结果（"可惜"）；后悔想要推翻结果（"不该"） |
| 无助 | 想改变但感觉什么都做不了 | 绝望 | 无助还在挣扎；绝望已经放弃了 |
| 绝望 | 看不到任何出路或希望 | 无助 | 绝望是彻底放弃了；无助还有想改变的愿望 |

## 羞愧 (Shame)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 羞愧 | 觉得自己整个人不好，想要藏起来 | 羞耻 | 羞愧偏内心感受；羞耻有更强的社会评判意味 |
| 尴尬 | 在社交场合中感到不自在，想要消失 | 羞愧 | 尴尬更短暂、更表层；羞愧更深层 |
| 内疚 | 觉得自己做了不该做的事，对不起别人 | 自责 | 内疚指向行为（"我做错了"）；自责指向自我（"我不好"） |
| 后悔 | 对过去的选择感到懊恼，希望能重来 | 遗憾 | 后悔想推翻过去的决定；遗憾更温和地接受 |
| 羞耻 | 觉得自己的某种特质或行为见不得人 | 羞愧 | 羞耻有外部评判的压力；羞愧更私人化 |
| 自责 | 反复批评自己，觉得一切都是自己的错 | 内疚 | 自责指向自我价值（"我这个人不行"）；内疚指向行为 |
| 厌恶 | 对某人或某事感到强烈的排斥和反感 | 反感 | 厌恶更强烈、更本能；反感更轻、更理性 |
| 反感 | 不喜欢、不想接近的感觉 | 厌恶 | 反感更温和；厌恶有生理上的排斥反应 |

## 惊讶 (Surprise)

| 情绪 | 定义 | 相似 | 区别 |
|------|------|------|------|
| 震惊 | 完全没有预料到，一时无法消化 | 震撼 | 震惊偏向"没想到"；震撼偏向"太厉害了" |
| 受惊 | 被突然的刺激吓了一跳 | 震惊 | 受惊是瞬间的生理反应；震惊需要时间消化 |
| 惊叹 | 被某事物的美好或厉害所折服 | 震撼 | 惊叹含有赞赏；震撼更强调冲击力 |
| 震撼 | 被某种力量深深地触动或冲击 | 惊叹 | 震撼更深层、更持久；惊叹更即时 |
| 惊喜 | 意外的好事带来的愉悦 | 高兴 | 惊喜含有"没想到"的成分；高兴不一定意外 |
| 困惑 | 不理解正在发生什么，找不到头绪 | 不安 | 困惑是认知层面的（"想不通"）；不安是情绪层面的 |
| 好奇 | 想要了解更多、探索未知的欲望 | 期待 | 好奇驱动探索（"这是什么"）；期待指向结果（"快来吧"） |
| 意外 | 事情的发展出乎预料 | 震惊 | 意外更中性；震惊更强烈 |
